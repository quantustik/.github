# Quantustik

Stock analytics for the S&P 500, built on a quantum-mechanics forecasting model
(Schrödinger equation + Feynman path integrals).

Every forecast comes with an explicit confidence band, an entry/exit reference
with an invalidation level, and a risk-first framing — never a bare "buy"
instruction. Unusually for this category, we publish our own calibration
record, including the horizons and tickers where the model is weakest.

- **Dashboard (free, no account):** https://quantustik.com
- **Calibration record:** https://quantustik.com/calibration
- **MCP server:** [`@quantustik/mcp-server`](https://github.com/quantustik/mcp-server) — `npx -y @quantustik/mcp-server`, or the hosted endpoint at `https://quantustik.com/mcp`
- **Public REST API:** https://quantustik.com/api

Informational analytics only — not investment advice, not a personalized
recommendation, and not a promise of profit.
